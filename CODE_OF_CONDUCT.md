# Code of Conduct

We are committed to a respectful, harassment-free community for everyone.

Be constructive, assume good intent, criticize ideas rather than people, respect privacy, and do not use the project to promote guaranteed returns or deceptive financial claims. Harassment, discrimination, threats, doxxing, and sexualized conduct are not acceptable.

Maintainers may edit or remove contributions and restrict participation when behavior is harmful. Report conduct concerns privately through the repository maintainers or GitHub reporting tools.

This policy applies in project spaces and when representing the project publicly.
