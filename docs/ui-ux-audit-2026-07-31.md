# ReplayTutor UI/UX 优化审计

日期：2026-07-31
范围：首页 → 训练配置 → 回放工作台 → 确定性复盘
目标：保持现有深色、高密度、图表主导设计系统，降低首次训练和恢复训练的认知成本。

## 总体结论

主流程已经可用，但优化前存在四个高影响问题：工作台被全局导航挤占、首页主行动重复、训练配置缺少阶段感、证据不足时复盘把不可评估指标显示为零。本轮已全部处理。

## 流程与结果

1. 首页：健康
   - 首次训练路径改为三个可扫读步骤。
   - 首次引导期间只保留一个主行动。
   - 可恢复会话改为显著的继续训练卡片。
   - 证据：[优化后首页](screenshots/ui-ux-audit-2026-07-31/after/01-home-1280.png)

2. 训练配置：健康
   - 增加“选择行情 → 绑定策略 → 开始训练”阶段条。
   - Session Contract 文案改为用户可理解的不可变规则与防未来数据说明。
   - 证据：[优化后训练配置](screenshots/ui-ux-audit-2026-07-31/after/02-session-setup-1280.png)

3. 回放工作台：1180px 健康，900px 可用但属于降级体验
   - 训练会话路由隐藏 84px 全局导航栏，将空间归还图表。
   - 1180px 下图表和决策台无横向溢出。
   - 900px 下仍无页面横向滚动，但图表内置 OHLC 标题较拥挤；完整窄屏抽屉仍应作为后续专项。
   - 证据：[优化后 1180px 工作台](screenshots/ui-ux-audit-2026-07-31/after/03-workbench-1180.png)
   - 降级证据：[900px 工作台](screenshots/ui-ux-audit-2026-07-31/after/05-workbench-900.png)

4. 确定性复盘：健康
   - `insufficient_evidence` 改为可读的“证据不足”。
   - 账户与成交事实继续显示真实零值。
   - 胜率、MFE/MAE、R 倍数和退出效率显示“未评估”，避免把无样本误解成零分。
   - 增加恢复动作“开始一场有效训练”。
   - 证据：[优化后复盘](screenshots/ui-ux-audit-2026-07-31/after/04-review-1280.png)

## 可访问性改动

- 增加“跳到主要内容”入口。
- 为链接、按钮、表单和可聚焦区域统一补充高对比焦点环。
- 增加 `prefers-reduced-motion` 降级。
- 工作台隐藏全局导航时不把不可见导航保留在辅助技术阅读顺序中。

## 验证

- `make verify`：通过。
- 前端：5 个测试文件、10 个测试通过。
- 后端：49 个测试通过。
- 浏览器控制台：0 个 error/warn。
- 900px 工作台：`scrollWidth = innerWidth = 900`，无页面横向溢出。
- 键盘跳转：激活跳转链接后焦点进入 `#main-content`。

## 证据边界

截图与自动化可以证明布局、文本、路由状态、控制台和基本键盘入口；不能单独证明完整 WCAG 合规。屏幕阅读器播报、长时间图表操作和 900–1179px 抽屉交互仍需要专项可用性测试。
