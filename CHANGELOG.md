All notable changes are documented here. The project follows semantic versioning while public APIs remain experimental during Alpha.

## 0.1.0-alpha.1 - 2026-08-02

### Added

- Local-first deterministic replay and paper-trading loop.
- Evidence-linked Codex Tutor and chart-context annotations.
- BTCUSDT/ETHUSDT spot and perpetual automatic public-data coverage.
- English/Simplified Chinese locale preference and API language negotiation.
- Explicit immutable Snapshot selection before account, replay-start, and strategy configuration unlock.
- Discoverable workbench shortcuts, local chart-layout persistence, and bilingual command and paper-order flows.
- Bundled Golden Dataset demo, Remotion video workspace, and browser recording workflow.
- Open-source community, security, architecture, and release documentation.
